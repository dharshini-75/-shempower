# SHEmpower – Women Self-Help Group Financial Management App

## About the Project

SHEmpower is a mobile application developed to simplify the financial management of Women Self-Help Groups (SHGs). It helps group leaders and members manage savings, loans, repayments, and financial records in a simple and transparent way.

The application reduces manual record-keeping and helps members track their financial activities efficiently.

## Key Features

- **User Authentication:** Secure login using mobile number and 4-digit PIN.
- **Member Management:** Separate access for group leaders and members.
- **Savings Management:** Track member savings and maintain savings records.
- **Loan Management:** Submit loan requests, manage approvals, and track outstanding balances.
- **Repayment Tracking:** Calculate interest using the reducing-balance method.
- **UPI Payment Verification:** Submit payment details and screenshots for verification.
- **Notifications:** Notify users about important financial activities.
- **Group Chat:** Enable communication between group members.
- **Notice Board:** Share important announcements with members.
- **Language Support:** Provide a Tamil language option for better accessibility.

## Technologies Used

- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Mobile Application:** Capacitor
- **Deployment:** Render

## User Roles

### Leader
- Manage group members.
- Monitor savings and loan activities.
- Review and approve loan requests.
- Verify repayment submissions.
- View financial records and notifications.

### Member
- View personal savings and loan details.
- Request loans when eligible.
- Track repayments and outstanding balances.
- Submit payment screenshots for verification.
- Access notifications and group communication features.

## Interest Calculation

SHEmpower uses the reducing-balance method to calculate loan interest. Interest is calculated based on the remaining principal balance.

**Formula:**

Interest = Remaining Principal × Monthly Interest Rate

For example, if the remaining principal is ₹5,000 and the monthly interest rate is 2%, the monthly interest is ₹100.

4. Configure the necessary environment variables.
5. Start the backend server.

*Note: Update the commands and environment variables according to your repository structure and configuration.*
